Projeto realizado para aula de Mobile. Foi utilizado Node.JS e React Native.
O sistema Law Bridge foi desenvolvido especialmente para um escritório de advocacia. Apresenta melhorias para a vida cotidiana dos funcionários do escritório, pois antes do sistema, os funcionários tinham as informações dos clientes e de cada processo digitada em arquivos Word ou manualmente. 
Com o sistema, todos os funcionários ganharam mais tempo, pois é bem simples de inserir os dados dos clientes e de seus processos.

Cadastrar, excluir e editar clientes;
Cadastrar e editar processos (podendo cadastrar também as varas em que tramitam, em que situação se encontram [se estão aguardando prazo, em processamento, conclusos pro juiz, etc]).
